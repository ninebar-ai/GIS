# .planning directory

Committed project memory for engineering execution.

## Files

- `PROJECT.md` - project identity and scope
- `REQUIREMENTS.md` - constraints and acceptance criteria
- `ROADMAP.md` - phase timeline and sequencing
- `STATE.md` - current status snapshot
- `CONTEXT.md` / `continue-here.md` - optional pause/resume context handoff
- `phases/<n>/PLAN.md` - phase plan
- `phases/<n>/VERIFICATION.md` - execution evidence
- `handoffs/*.md` - human/agent transfer documents (from `process/templates/HANDOFF.md`)

## Rules

- Update `STATE.md` after each substantial change.
- Do not close a phase without `VERIFICATION.md`.
- Record rejected options to avoid repeated rework.
