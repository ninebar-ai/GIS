# Junk Folder Policy

`junk/` contains non-essential local artifacts that are not part of runtime, process governance, or canonical documentation.

Typical contents:
- one-off generated office exports (`.docx`, `.pdf`);
- scratch scripts used for temporary artifact generation;
- workspace HTML dumps and debug files;
- ad-hoc diagrams not required by product/runtime docs.

Only this `README.md` is tracked. Everything else under `junk/` is ignored by git.
