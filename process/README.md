# Process Assets

This directory contains reusable workflow assets for the repo.

- `USAGE.md` - full operational walkthrough.
- `APPROACH.md` - short path guide.
- `prompts/` - copy/paste command prompts for scaffold, join, handoff, review.
- `rules/` - non-negotiables, done criteria, review checklist.
- `templates/` - artifact templates used during onboarding and handoffs.

These files are aligned to `gsd-core-next` command conventions.
